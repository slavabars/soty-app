# Глоссарий и пайплайн локализации

**Русский** · [English](l10n_glossary.en.md)

Каждая поставляемая локаль — отдельный ресурс под `lib/core/i18n/locales/`: `ru, zh, hi, es, fr, ar, bn, pt, id, de, it, tr, ja, ko, th, vi`. `soty_l10n.dart` хранит API поиска (`SotyL10n.tr`, `forLocale`, плюрализация, `_unchangedKeys`) и подключает файлы локалей директивами `part`.

## Правила

- Английский ключ — исходная строка и fallback. Никогда не переводите сам ключ; переводите его значение.
- Каждый ключ должен существовать в каждой локали. Иначе `test/unit/l10n_keys_test.dart` валит сборку, а `hasTranslation` проверяется для каждой локали.
- Плейсхолдеры используют `{name}` и должны пережить перевод без изменений.
- Числовые строки могут добавлять формы множественного числа: `'key|one|few|many|other'`; аргумент `n` выбирает категорию.
- Язык, который заимствует слово без изменений (бренд, «Emoji»), должен быть перечислен в `_unchangedKeys`; не откатывайтесь молча на английский.
- Не переносите строки внутри предложения: форматтер Dart управляет кодом, но отрендеренный текст не должен получать переносы.
- Арабский — RTL: сохраняйте логический порядок в тексте, без ручных символов направления.

## Глоссарий

| Английский | Значение |
| --- | --- |
| Soty | Название продукта, никогда не переводится |
| relay host / relay | Операторский сервер, который хранит только зашифрованные конверты |
| envelope | Один зашифрованный кадр wire (шифртекст + метаданные) |
| safety number | Отпечаток Ed25519+X25519, который сверяют собеседники |
| identity | Пара ключей Ed25519/X25519 устройства |
| backup | Зашифрованный файл идентичности, контактов и истории |
| mesh | Офлайн-транспорт BLE/Wi-Fi Direct |
| peer | Другое устройство/пользователь в адресной книге |
| tracker | Возможность релея выдавать привязки пиров |

Переводите «relay» как сетевой релей, а не как радиорелей. Оставляйте «Soty», «Ed25519», «X25519», «AES-256-GCM», «Argon2id», «QR» и «GitHub» без изменений.

## Статус нативной вычитки

Волна 1 (`de, it, tr, ja, ko, th, vi`) полностью переведена и покрыта тестами полноты, но тексты ещё не читали носители. Проверяйте тексты приложения и сайта до объявления локали финальной: следите за формами множественного числа (немецкий, итальянский и турецкий используют `|one`), переносами строк в CJK и тоном UI-подписей в тайском и вьетнамском.
