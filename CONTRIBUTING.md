# Участие в Soty

**Русский** · [English](CONTRIBUTING.en.md)

Спасибо, что нашли время помочь. Soty — чувствительный к безопасности serverless-мессенджер: корректность и обработка недоверенного ввода важнее новых функций.

## Перед началом

- Прочитайте `docs/threat_model.md` перед изменением криптографии, транспортов или парсинга.
- Для нетривиальной задачи сначала откройте issue, чтобы мы согласовали подход.
- Проблемы безопасности — в `SECURITY.md`, **никогда** в публичный issue.

## Разработка

```bash
export PATH="$HOME/development/flutter/bin:$PATH"
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64

flutter pub get
flutter analyze --no-pub
flutter test --no-pub
```

Drift и модели `json_serializable` генерируются:

```bash
dart run build_runner build
```

`lib/core/storage/database.g.dart` должен быть актуален в каждом коммите.

## Правила

- **Сначала тест.** Изменение поведения без теста неполно. Покрывайте и враждебный путь: replay, неверная подпись, чужой ключ, слишком большой фрейм, сдвиг часов, битая deep link.
- **Лимиты живут в `lib/core/security_limits.dart`.** Никогда не хардкодьте байтовый или количественный предел в другом месте.
- **Никогда не логируйте** seeds, плейнтекст, расшифрованные данные и ошибки AEAD.
- **Держите существующий стиль.** Дерево не проходит `dart format` под текущим SDK; не переформатируйте файлы целиком.
- Один логический change на pull request.
- Не добавляйте аналитику, телеметрию и сторонние трекеры.
- Не переносите строки в доках, шаблонах и commit messages вручную: один абзац или пункт списка — одна строка исходника.

## Pull requests

- Опишите, что изменилось и почему; свяжите issue.
- Укажите, что проверили (`flutter analyze`, `flutter test`, e2e если относится).
- CI должен быть зелёным. Ночные прогоны идут по расписанию, поэтому нестабильный тест будет замечен.
- Отправляя код, вы соглашаетесь на лицензию AGPL-3.0 (см. `LICENSE`).

## Commit messages

Короткий императивный заголовок, затем тело с объяснением «почему». Ссылайтесь на тест, который покрывает изменение.
